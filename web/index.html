Control Your PlayStation 4 with an Infrared Remote

Firmware Flashing Methods

Choose one of the following methods to transfer the precompiled firmware to your Arduino Leonardo board.

1

PlatformIO Core

Compile and flash with a single command:

pio run --target upload
2

Makefile Workflow

Execute the automated build and flash target:

make run
3

Direct AVRDUDE Flash

Flash the downloaded HEX binary via Caterina bootloader:

avrdude -p atmega32u4 -c avr109 -P /dev/ttyACM0 -U flash:w:firmware.hex:i

Hardware & Wiring Specification

Connect your 3-pin 38 kHz infrared receiver module (VS1838B) to the Arduino Leonardo according to the schedule below.

Pin Connections Table

Leonardo Pin Firmware Identifier Receiver Terminal Function
Pin 2 (PD1) RECV_PIN Data / OUT Interrupt-driven capture of demodulated optical pulses
Pin 3 (PD0) RECV_EN VCC (Power) Active-HIGH 5V supply and power stabilization control
GND GND GND (Ground) Common system reference ground
Micro-USB D+ / D- / VBUS PlayStation 4 USB 5V power supply and native USB HID keyboard reporting

Electrical Guidelines

  • Controlled Power Supply: Pin 3 drives receiver VCC HIGH with a 10 ms stabilization delay during setup(), preventing floating input spikes during boot.
  • Decoupling Filter: When using jumper wires exceeding 15 cm, place a 0.1 µF ceramic capacitor across receiver VCC and GND to filter USB line ripple.
  • Optical Shielding: Avoid placing the receiver under direct sunlight or adjacent to unshielded CFL lamps to prevent false interrupt triggering.

Quick Start

Clone, compile, and flash the firmware in three commands.

1

Clone Repository

Download the source tree to your workstation:

git clone https://github.com/AtaCanYmc/RemoteStation.git && cd RemoteStation
2

Compile Firmware

Build the binary for the Arduino Leonardo target:

make build
3

Flash & Connect

Flash the MCU and plug into the PlayStation 4 front USB port:

make upload
